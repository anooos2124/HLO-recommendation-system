# متابعة تجربة HLO على الأنطولوجيا

تسترجع التجربة الفئات الأب المباشرة المسمّاة في ملف HLO الأصلي. يولّد المشروع صياغتين لكل فئة ذات اسم فريد، ويبقيهما في التقسيم نفسه. تُراجع إجابات SPARQL مقابل علاقات `rdfs:subClassOf` المصرّح بها في الأنطولوجيا.

| التقسيم | الأسئلة | الفئات |
| --- | ---: | ---: |
| التدريب | 1,922 | 961 |
| التحقق | 642 | 321 |
| الاختبار | 642 | 321 |

توجد سجلات التقسيم المولّدة في `data/ontology-derived/`. يعيد السكربت توليدها للتحقق من تطابقها مع الأنطولوجيا في كل تشغيل.

يدخل معرّف الفئة المكتوب في السؤال إلى النموذج. تُربط الفئة بالبادئة `focus:`، ويولّد mT5 جسم الاستعلام. لهذا تقيس هذه المجموعة تعلّم صيغة الاستعلام عند معرفة الفئة والعلاقة. قالب SPARQL مرجع حتمي للمهمة نفسها. توسيع الادعاء إلى تعميم علاقات جديدة يحتاج مجموعة اختبار تناسب ذلك.

## التشغيل

من جذر المشروع، نفّذ فحص البيانات والاختبارات والقالب:

```bash
python tools/train_hlo.py --check-only
```

في جلسة GPU شغّل التدريب والتقييم:

```bash
python tools/train_hlo.py
```

يدعم السكربت أيضًا `--from-github` لسحب التزام GitHub المثبّت وتطبيق تعديلات مسار الأنطولوجيا المرفقة معه. يتوفر نوتبوك في `Notebook/Colab/HLO_Ontology_Training.ipynb`. عند فتحه في Colab، فك ضغط الحزمة تحت `/content` وحدد جذر المشروع في الخلية الأولى ثم فعّل `TRAIN_MODEL` عند جاهزية GPU.

يحفظ كل تشغيل `hlo-training.log` و`run-summary.json` في مجلد مستقل تحت `hlo-runs/`. عند اكتمال التدريب تظهر نقطة الحفظ وسجل الدورات وتنبؤات كل نظام. تجارب BKT والسياسة تتطلب ملفات المتعلمين المراجَعة في `data/reviewed/`.

## عرض النتائج

اعرض Answer F1 ومتوسط صلاحية التنفيذ وعدد الاستعلامات المنفّذة على أسئلة الاختبار نفسها. عند توفر تنبؤات mT5، احسب الفرق الزوجي وفاصل الثقة 95% بإعادة أخذ العينات من الفئات الـ321. اعرض نتائج BKT والترتيب وأثر التعلم عند توفر البيانات المناسبة لكل تجربة.

| النظام | الاستعلامات المنفّذة | Answer F1 |
| --- | ---: | ---: |
| قالب SPARQL | 642 / 642 | 1.000 |
| mT5 | بانتظار التدريب الكامل | — |

[نسخة المحادثة](HLO-Shared-Conversation.md) تتضمن الخطوات والنتائج التاريخية. يسجل مجلد `verification/` فحص الدمج الحالي.

## سجلات التشغيل وWeights & Biases

يحفظ كل تشغيل `hlo-training.log` للأوامر والمخرجات و`hlo-events.jsonl` لأحداث المراحل ومقاييس الدورات ونتائج التقييم، إضافة إلى `run-summary.json`. تظهر في W&B خسارة التدريب وAnswer F1 وصلاحية استعلامات التحقق لكل دورة، ونتائج الاختبار لكل نظام. يحتفظ المشروع بالنصوص والتنبؤات والأوزان ضمن مخرجات التشغيل المحلية.

```bash
python -m pip install -e '.[tracking]'
python tools/train_hlo.py --check-only --wandb-mode offline
```

للتسجيل عبر الإنترنت، سجّل الدخول باستخدام `wandb login` أو اضبط `WANDB_API_KEY` في بيئتك، ثم شغّل:

```bash
python tools/train_hlo.py --wandb-mode online --wandb-project hlo-recommendation
```

اضبط `--wandb-entity` إذا كان المشروع تابعًا لفريق. في Colab استخدم Secrets للمفتاح واضبط `WANDB_MODE = 'online'`. يحفظ وضع `offline` ملفات W&B داخل مجلد التشغيل، ويمكن رفعها لاحقًا باستخدام `wandb sync <run-directory>/wandb/offline-run-...`. وضع `disabled` يحفظ السجلات المحلية فقط.
